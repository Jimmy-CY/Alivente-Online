{% comment %} TR-10, 16 Nov 2026 - the order of a day, by dragging a grip; the same on the phone and the computer. Demetri, 16 Nov: "I am not happy how the sorting happens on the mobile. It is cumbersome and not user intuitive." Each day is a [data-reorder] box (data-url, data-day, data-custom) holding rows [data-key], each with a grip [data-grip]. Only the grip starts a drag (touch-action: none on it), so the rest of the row still scrolls the page and opens the booking. The row lifts and follows the finger; the others slide aside; near the top or bottom of the screen the page scrolls. On release the order is saved at once, and "Order saved - Undo" shows for a few seconds. Arrow keys on a focused grip move it too. {% endcomment %}
