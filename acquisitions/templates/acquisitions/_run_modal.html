Running a search

Searches are run by Claude’s scheduled tasks, not by Alivente Online — the property sites block searches from a data centre like the one the app runs in.

To run one now, open the Claude app, go to Scheduled tasks and press Run now on “Daily Nicosia apartment search”.

For the sites that block the cloud (Bazaraki, Spitogatos, DOM), open the session from the daily email on your computer and type PC. Keep the Claude desktop app open and the laptop awake.

Once Claude is connected to the app, this button will start the search itself.
