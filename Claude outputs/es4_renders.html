The signing page

ES-4. One page, two ways in: a tenant’s emailed link, or the Alivente signer already signed in. The document is served through the same token check as the page, never from a media URL — a seven-day link should not outlive its own expiry.

The renders earned their keep. The first build shipped with the lock already open. The page images are lazy, a lazy image that has not loaded is zero pixels tall, so all three pages stacked at the same point, the end-of-document marker sat in the viewport on arrival, and the button unlocked before a word had been read. Reading the markup would never have shown it. The suite now drives this in a browser at both widths.

The page arrives locked

The requirement is stated before the document, the progress strip tracks where they are, and the control says what is still outstanding instead of sitting grey. Reaching the last page unlocks that half.

Ready to sign

Drawn with a finger or a mouse, or typed if that is easier. The trail records which it was. The consent sentence sits above the button, not behind a link.

After the seventh day

No document, no controls, and the reason stated. Not a silent 404, because a tenant who was merely slow would not know whether they had the wrong link or missed a deadline.
