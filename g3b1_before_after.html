Five Headers Come Home

G3b-1 — five Personal pages hand-rolled the same header: title and description on the left, controls on the right. The house puts a centred title first and the action bar under it.

The title loses its icon. Measured across the 88 pages already on .page-title-h2: 87 are uppercase and not one carries an icon. The class is centred and sets no text-transform, so the capitals live in the markup.

The descriptions are kept, below the bar. G1 dropped the sentences under its sixteen banners and that was right — a subtitle is a MODE label. These five are not decoration: pantry_staples’ explains that a staple never counts as missing, which is the whole behaviour of the screen. There was nowhere house to put them — five pages had each invented a name for this one line and base declared none of them — so base gains .page-note.

Rendered from the backup (before) and from the changed file (after), same stylesheet, at 1280 px and 390 px. Icons are missing because Font Awesome is not loaded in the fixture.
