What is this report?

The Forecasted Cash Outflows dashboard shows the predictable, budgeted expenses coming up over the next 12 months across your entire portfolio. Its purpose is cash planning — seeing where the big months are, so you can make sure the bank account is ready for them.

Important — this is a budget forecast, not a record of actual expenses.

Every amount shown here comes from the Expense records you've configured in Financials → Configuration → Expenses. These are the recurring, yearly-repeatable, predictable expenses (Property Manager fees, Communal Fees, annual audit, Company Tax, etc.) — the ones you already know about in advance. There are no approvals, no invoice statuses, and no unexpected one-off expenses. For those use the Expenses module in the main sidebar instead.

The rolling 12-month horizon

The forecast always starts with today's current month and projects 12 months forward. Next month it rolls automatically — what was "month 2" becomes "month 1" and a new month is added at the end. You never need to change the dates yourself.

Three views of the same data

The dashboard presents the same underlying data in three complementary ways:

  1. Three summary cards at the top — time-bucketed totals (Current Month / Next 3 Months / Remaining Months)
  2. Bar chart below — month-by-month breakdown across the full 12-month horizon
  3. Drill-down modal — click any bar to see which Expense Line Types drive that month, then click any Line Type to see the property-level breakdown
Where the data comes from

For each Expense record in Configuration, the system:

  1. Checks its Expense Type to see which months are flagged (e.g. Monthly = all 12 months, June = just June, Quarterly = Jan/Apr/Jul/Oct)
  2. For each flagged month within the rolling 12-month horizon, records the Expense Amount as "due" in that month
  3. Aggregates across all properties and all Line Types to produce the monthly totals

A change to any Expense record — or any Pro-Rata distribution — flows through to this report automatically, with no cache to refresh.

Reading the Dashboard
The three summary cards
  • Current Month (red) — total budgeted outflow for the month you're currently in (the "imminent" bucket). This is what you need to cover right now.
  • Next 3 Months (orange) — total for months 2 through 4 (31 to ~90 days ahead). Near-term cash planning.
  • Remaining Months (green) — total for months 5 through 12 (over 90 days out). The horizon for longer-term reserve planning.
The colour palette signals urgency, not risk. Red doesn't mean "bad" — it means "imminent, happening now." Orange means "coming slowly." Green means "there's still time."
The 12-month bar chart

Each bar represents one month's total budgeted outflow. Bars are coloured using the same red/orange/green convention as the summary cards, so scanning left-to-right you can see urgency fading:

  • Leftmost bar (red) — current month
  • Next three bars (orange) — the 31-90 day zone
  • Remaining eight bars (green) — more distant, over 90 days away

Each bar is labelled with the month/year (e.g. Apr 2026) and the total amount (e.g. €2,176.14).

The gridlines and scale

The Y-axis auto-scales to fit your data. Gridlines appear at round intervals (€1,000 increments for typical portfolios, smaller increments for smaller totals). Gridline labels like €5,000 or €10,000 appear on the left-hand side for reference.

Interactions
  • Hover a bar — it slightly scales up to confirm it's clickable
  • Click a bar — opens the Monthly Expense Breakdown modal for that specific month
  • See the next tab (Drilling In) for what happens once you click
Spotting the patterns

One of the main uses of this report is spotting irregular months. Most months will look similar (monthly recurring expenses like Property Manager fees, utilities, and Communal Fees dominate), but certain months stack on top of that a concentration of annual bills — audit fees, property taxes, insurance premiums. Those months stick out visually as taller bars.

Seeing a €12k month among a run of €2k months is a visual warning: make sure the cash reserve can cover it.

Drilling into the detail

The dashboard is designed as a two-level drill-down — from month to expense line type to property.

Step 1 — Click a bar

Clicking any bar opens the Monthly Expense Breakdown modal. It shows:

  • Total Month — the sum across all Line Types for that month (e.g. Total Month: €12,313.34)
  • A table with two columns: Expense Line Type and Total Amount, sorted alphabetically
  • Each row is clickable and shows a chevron on the right to signal that
Step 2 — Click a Line Type row

Clicking a Line Type row (e.g. Financials (Cyprus) — €2,810.00) drills into that Line Type and shows the property-level breakdown:

  • A summary card showing the Total Amount and Line Type name
  • One card per property contributing to this Line Type in this month, with:
    • The property name
    • The euro amount for this property
    • The percentage of the Line Type's total this property contributes (e.g. 10.44%)

For a Pro-Rata Line Type, you'll see multiple properties (the distribution). For a standard Line Type, usually just one property per bill.

Step 3 — Going back

From the property-level view, a Back to Monthly View button appears in the modal footer. Clicking it returns you to the Line Type list for the same month. You can drill in and out freely without closing the modal.

A worked example

Take the June bar on the chart, which is typically much higher than the months around it. Clicking it might show:

  • Financials (Cyprus) — €2,810 (annual audit, due in June)
  • Prop Tax (Greece) — €714.34 (annual Greek property taxes)
  • Company Tax — €6,999.99 (annual corporate tax)
  • plus the usual recurring monthly items (Property Manager, Cleaning, etc.)

Drilling into Financials (Cyprus) would then show the split across all 10 Cyprus properties, e.g. Eleftheroupoleos: €293.38 / 10.44%, Ionion - Villa 24: €412.56 / 14.68%, etc. — the same Pro-Rata distribution you set up in Configuration.

This makes June visually distinct on the chart, and the drill-down explains why it's distinct.

Practical Tips
Using the dashboard for cash planning
  • Scan the chart at the start of each month. The current-month bar tells you what to cover in the next 30 days; the orange bars tell you what's coming in the 60 days after that. Build your cash reserve around the biggest of the visible bars.
  • Identify the "annual bills" months. Most portfolios have 1-3 months a year where annual bills stack up (audit fees, property taxes, insurance renewals). The chart makes them visually obvious — they're the bars that are 3-5× taller than their neighbours. Make sure you're aware of which months those are for your portfolio.
  • Drill into unusual bars. If a month looks unexpectedly high or low, click the bar and check the Line Type list. Often you'll spot a one-off annual bill you'd forgotten about, or a missing bill that should be scheduled but isn't.
  • Use the property drill-down to verify Pro-Rata distributions look right. Click into a Pro-Rata Line Type for any month and confirm the per-property percentages match what you'd expect (they should reflect each property's relative Current Value).
Fixing numbers that don't match reality
  • If a forecast month is too low, an Expense record is probably missing. Go to Configuration → Expenses, find the property that should have the missing record, and add it.
  • If a forecast month is too high, look for a double-counted Expense or a wrong Expense Type. E.g. an expense paid quarterly but set to Monthly in Configuration will triple-count. Drill into the Line Type to spot the culprit.
  • If a Pro-Rata Line Type's total doesn't match the bill, check the Line Type's Pro-Rata Amount field. If it's stale, edit it — the Line Type page will walk you through the cascade so every property's expense gets updated automatically.
  • If a property's share looks wrong, check its Current Value on the Property Valuations page. A stale Current Value skews the pro-rata split. Updating it will trigger the Valuations cascade modal to update every affected distribution.
General awareness
  • This report reflects Configuration instantly. Any change to an Expense record, Expense Line Type, or Property Valuation that affects Pro-Rata is visible here immediately on next page load — no refresh or rebuild needed.
  • One-off expenses won't show here. Unexpected repairs, emergency maintenance, and ad-hoc supplier invoices are handled by the Expenses module in the sidebar — separate from this forecast. Don't expect them to appear.
  • The forecast is your portfolio's "expected pulse". Over time you'll know intuitively what a normal month looks like (e.g. €2,000) and which months are spikes (e.g. €12,000). When a month looks wrong — neither normal nor an expected spike — that's a strong signal to investigate before the month arrives.
This dashboard is your 12-month cash radar. Keep Configuration tidy and this report becomes a reliable early-warning system for when big bills are coming — so they never arrive as a surprise.
