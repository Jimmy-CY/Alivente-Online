What is the Properties Module?

The Properties module is the central hub of Alivente Online. It allows you to manage your entire property portfolio — from recording property details and locations to tracking assets, title deeds, utility accounts, and generating property reports.

Key Features
Property List
View all your properties at a glance with their country, status, and quick-access action buttons.
Map View
See all your properties plotted on an interactive map. Instantly visualise your portfolio's geographic spread.
Property Reports
Generate a detailed report for any property including address, specifications, utility accounts, insurance, and a full asset summary.
Title Deeds
Upload and store PDF title deeds for each property. View and download them at any time directly from the property list.
Asset Tracking
Record and manage all physical assets (appliances, electronics, furniture) within each property, including warranty tracking.
Filtering
Filter properties by country, status, and other criteria to quickly find what you need.
Important: Properties marked as Active and Available for Rent are included in vacancy calculations across the system. Make sure your property statuses are kept up to date.
Understanding the Property List

Each row represents one property. The columns are:

Column Description
Property The property name as entered in the system.
Country The country where the property is located.
Status Active — Included in all calculations.
Inactive — Excluded from vacancy and occupancy calculations.
Details Opens the Edit Property form.
Report Generates a full Property Details Report including address, specifications, utility accounts, and asset summary.
Title Deed Opens the stored title deed PDF. Shows "Unavailable" if none has been uploaded.
Assets Opens the Asset Manager for this property. Shows "None" if no assets recorded.
Using Filters

Click the Property Filters bar to expand filter options. Filter by property name, country, and status. Use Clear All to reset all filters.

Map View

Click Map View to see all properties as pins on an interactive map. Use Center Map to reset the view to show all properties.

Adding and Editing Properties

Click Add New to create a property, or Edit on any row to update it. Both forms contain the same fields.

1 Property Name
Give it a clear descriptive name (e.g. "Ionion - Villa 24"). This appears throughout the system.
2 Address
Fill in the full address — Address 1, Address 2, Suburb, City, Province, Country, Post Code. A complete address ensures accurate map placement and correct reports.
3 Map Location
Click directly on the map to drop a pin, or use Find Address on Map to auto-locate. Use Clear Location to remove a saved pin.
4 Specifications
Enter Floor Area (m²), Year Built, and whether to Include in Occupancy Calculations. Setting this to "Yes" means this property counts in vacancy metrics on the Dashboard and Notifications.
5 Status & Availability
Status — Active or Inactive. Available for Rent — Properties set to Active + Available for Rent with no tenant will appear as vacant in Notifications. Title Deed Available — Indicates whether a deed exists.
6 Utility Accounts
Record account numbers for Electricity, Water, Refuse, Property Tax, Sewerage, and Insurance. These appear on the Property Report and serve as a central reference for all service accounts.
Managing Property Assets

Each property can have unlimited assets — appliances, electronics, furniture, and more. Assets are grouped by category.

Accessing Assets

Click View in the Assets column. If no assets exist, click Edit on the property and use the Assets button in the top-right corner.

Tips and Best Practices
Always set the map location
Use "Find Address on Map" after entering the address for best accuracy. This ensures the property shows correctly in Map View.
Keep status up to date
Active + Available for Rent properties with no tenant appear as vacant in Notifications. Update statuses promptly to keep your data accurate.
Upload title deeds early
Upload title deed PDFs as soon as they're available. This creates a secure, centralised location for all your legal property documents.
Record assets with warranty dates
Always enter warranty expiry dates. This lets you track which items still have coverage and which need attention.
Fill in utility account details
Enter account numbers for electricity, water, refuse, and other services. Easy reference without searching through paperwork.
Use the Property Report regularly
The Property Details Report is a comprehensive one-page summary. Print or share it when meeting lawyers, accountants, or tenants.
