What is the Properties Module?

The Properties module is the central hub of Alivente Online. It lets you manage your entire property portfolio — from recording property details and locations to tracking assets, title deeds, utility accounts, and generating property reports.

Every other module in the system depends on the data you capture here. Tenants attach to properties; revenues, expenses, and valuations all reference properties; reports like the P&L and Vacancy Management aggregate data across properties. Getting this module right pays dividends everywhere else.

Key features
Property List

Every property at a glance with its country, status, and quick-access action buttons for editing, viewing the report, opening the title deed, and browsing assets.

Map View

See all properties plotted on an interactive map. Instantly visualise your portfolio's geographic spread. Click Map View in the top action bar.

Property Reports

Generate a detailed report for any property — address, specifications, utility accounts, insurance, status, and a full asset summary. Useful for meetings with lawyers, accountants, or tenants.

Title Deeds

Upload and store PDF title deeds for each property. View and download them at any time directly from the property list — a secure, centralised home for your legal documents.

Asset Tracking

Record every physical asset (appliances, electronics, furniture) within each property, including brand, purchase date, supplier, and warranty expiry.

Filtering

Filter properties by name, country, and status. Active filters are shown as removable tags. Use Clear All to reset.

Important: Properties marked as Active and Available for Rent are included in vacancy calculations across the system. Make sure your property statuses are kept up to date — stale statuses lead to misleading dashboards.
Understanding the Property List

Each row on the table represents one property. The columns are:

The 7 columns
  • Property — The property name as entered in the system.
  • Country — The country where the property is located (Cyprus, Greece, Spain, etc.).
  • Status — Either Active (included in all calculations) or Inactive (excluded from vacancy and occupancy calculations).
  • Details — Opens the Edit Property form (superuser-only for editing; others see a disabled button).
  • Report — Generates the full Property Details Report (address, specifications, utility accounts, asset summary).
  • Title Deed — Opens the stored title deed PDF in a viewer. Shows "Unavailable" if none has been uploaded.
  • Assets — Opens the Asset Manager for this property. Shows "None" if no assets have been recorded.
Using the filter panel

Click the Property Filters bar at the top to expand filter options. You can filter by:

  • Search Property — free-text search on the property name
  • Country — dropdown with each country represented in your portfolio
  • Status — Active or Inactive

Filters are combinative — all selected filters apply at the same time. Active filter tags appear at the bottom of the panel and can be removed individually, or use Clear All to reset everything.

Map View

Click the Map View button at the top to see all properties as pins on an interactive map. The pins respect the current filter — so if you're filtered to Cyprus only, only Cyprus properties appear on the map. Use Center Map to reset the zoom to show all visible properties.

Tip: For a property to show on the Map View, its address must be correctly geocoded. If a property is missing from the map, open its Edit form and check the map location — you may need to use Find Address on Map to set or correct the pin.
Adding and Editing Properties

Click Add New in the top-right to create a new property, or the Edit button on any row to update an existing one. Both forms contain the same six sections.

1. Property Name

Give it a clear, descriptive name (e.g. "Ionion - Villa 24"). This name appears throughout the system — on the P&L rows, in tenant records, in reports, on maps. A consistent naming convention helps enormously: prefix by building or area, then unit identifier.

2. Address

Fill in the full address — Address Line 1, Address Line 2, Suburb, City, Province, Country, Post Code. A complete address ensures accurate map placement and correctly-rendered reports.

3. Map Location

Two ways to set the pin:

  • Click directly on the map — drops a pin at the clicked location
  • Use "Find Address on Map" — auto-locates the pin based on the address fields you've filled in

Use Clear Location to remove a saved pin. A pin is required for Map View to display the property.

4. Specifications
  • Floor Area (m²) — used for the Rent/m² KPI on Financial Indicators
  • Year Built — informational
  • Include in Occupancy Calculations — Yes means this property counts on Vacancy Management and Performance Trends. Set to No for owner-occupied properties, short-term/summer-let properties, or properties not rented on a traditional basis.
5. Status & Availability
  • Status — Active or Inactive. Inactive properties are hidden from most reports.
  • Available for Rent — Active + Available for Rent + no current tenant = counts as Vacant in Notifications and the Dashboard.
  • Title Deed Available — indicates whether you hold a deed for this property. The actual PDF is uploaded separately.
6. Utility Accounts

Record account numbers and supplier info for:

  • Electricity
  • Water
  • Refuse
  • Property Tax
  • Sewerage
  • Insurance

These appear on the Property Report as a central reference for all service accounts, so you don't have to search through paperwork when a bill arrives or a service needs to be contacted.

Adding vs Editing: The form is identical in both cases — the only difference is that Add New starts blank, while Edit pre-fills every field with the current values. Only Superusers can add properties; Superusers and ordinary users can edit (check the row-level button to see your permission).
Managing Property Assets

Each property can have unlimited assets — appliances, electronics, furniture, and more. Assets are grouped by category in the Asset Manager, and are summarised in the Property Report.

Accessing the Asset Manager

Two ways to open a property's assets:

  • From the Property List — click View in the Assets column (only appears if at least one asset exists)
  • From the Edit form — open the property's Edit form, then click the Assets button in the top-right. This works even if no assets exist yet — it's how you add the first one.
Information recorded per asset
  • Asset Name — e.g. "Samsung Washing Machine"
  • Brand — the manufacturer
  • Category — Appliances, Electronics, Furniture, etc.
  • Subcategory — e.g. Air Conditioner, TV, Sofa
  • Location / Room — e.g. Lounge, Kitchen, Master Bedroom
  • Purchase Date — when the asset was acquired
  • Supplier — where it was bought
  • Warranty Expiry Date — when the warranty ends
Warranty status

Each asset shows one of three warranty badges:

Active — warranty expiry is in the future; the asset is still under warranty.
Expired — warranty expiry is in the past; repairs are now at your cost.
N/A — no warranty expiry date recorded (incomplete data).
Property Report integration: The Property Details Report includes an Asset Summary section showing total asset count, active vs expired warranties, total purchase value, and maintenance cost indicators. Keep assets up to date and the report becomes a powerful portfolio inventory.
Practical Tips
Setting properties up correctly
  • Always set the map location. After entering the address, use Find Address on Map — it auto-places the pin with good accuracy. Properties without a pin won't appear on Map View.
  • Keep statuses up to date. Active + Available for Rent properties with no tenant show as Vacant in Notifications. Stale statuses mislead the whole dashboard — update as soon as a property goes into or out of service.
  • Upload title deeds early. As soon as a deed becomes available, upload the PDF. It creates a secure, centralised home for your legal documents and makes them easy to share with lawyers, tax authorities, or potential buyers.
  • Choose consistent naming. Whatever convention you pick ("Building - Unit", "City-StreetName", etc.), use it for every property. Reports, dropdowns, and filters all work better with predictable names.
Capturing assets properly
  • Record warranty dates when you capture the asset. Once the receipt is filed away, warranty info is easy to forget. Enter it the moment the asset is installed.
  • Use meaningful Location/Room values. "Kitchen" and "Master Bedroom" are much more useful than generic labels when a maintenance engineer needs to know where to go.
  • Keep supplier info. When an item fails, knowing where it was bought (and whether it's still under warranty) saves hours of scrolling through emails.
Making the module work for you
  • Fill in utility account details. Account numbers for electricity, water, refuse, and other services centralised in one place saves time every time a bill needs to be queried.
  • Use the Property Report regularly. The one-page Property Details Report is the best summary document for meetings with lawyers, accountants, property managers, or tenants. Print or PDF-export before any such meeting.
  • Use Map View for portfolio reviews. Visualising your portfolio geographically can reveal patterns — a cluster of underperforming properties in one area, or over-concentration in a single city.
  • Remember the Include in Occupancy flag. This flag on each property controls whether it appears on Vacancy Management and Performance Trends. Owner-occupied or short-term rentals should be set to No; long-term rentals should be set to Yes.
Properties is the foundation. Every other module in Alivente Online — Tenants, Revenues, Expenses, the P&L, Vacancy Management — builds on the data you capture here. Time spent keeping property records accurate and complete is repaid across the entire system.
