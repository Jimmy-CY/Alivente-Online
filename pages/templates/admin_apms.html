What is the Administration page?

Administration is the central hub for property-document workflows and system-wide settings. The page is split into two tabs:

  • Functional — day-to-day property document tasks: lease agreements, title deeds and invoice generation.
  • System — account and application settings: user management and menu preference.
The Notifications button

The Notifications button (top-right) takes you to Administration Notification Settings, where you configure who receives operational emails — daily property reports, invoice and expense alerts, the Friday Status Report, and so on.

Superuser only: The Administration tabs and cards are visible only to Superuser accounts. Regular users see the Alivente logo on this page instead.
Functional cards

Four cards covering lease, deed and invoice document workflows:

Manage Lease Agreements

Opens the Tenant Lease Agreements — Upload / View / Delete page, listing every tenant lease with its property, start and end date.

  • View — opens the uploaded lease PDF
  • Upload — appears when no lease is on file yet
  • Delete — removes an uploaded lease document
  • End dates shown in red are expired
Generate Lease Agreement

A 3-step wizard that generates a new lease document from scratch using pre-defined templates with placeholders.

  • Step 1 — pick the Country (Cyprus, Spain or Greece) and Language (English or Greek)
  • Step 2 — select the Property and Tenant, then complete additional data: passport / ID, lease terms (rent, deposit, dates, communal expenses, extension, rental increase), landlord information, amenities, furniture & appliances, and keys provided
  • Step 3 — click Generate Lease Agreement to produce the final document

A second tenant can be added in Step 2 via + Add Second Tenant.

Manage Title Deeds

Opens the Property Title Deeds — Upload / View / Delete page, listing every property with its address, year, area and status. Same Upload / View / Delete pattern as the lease agreements page, but for property title deed documents.

Generate Invoices

Tenant invoices are automatically generated on the 1st of every month. You normally don't need to do anything — just check that they appear.

Use this card when you need to generate invoices on the fly — for example, if the automatic run was missed for any reason, or you've added a new tenant mid-month and need their invoice straight away. The system only creates invoices that haven't already been generated, so it's safe to click any time.

Tip: The Notifications Dashboard shows Overdue Invoices at a glance — a quick way to confirm the automatic monthly run did its job.
System cards

Four cards (two active, two reserved for the future) covering account and application settings:

User Administration

Manage the people who can log into the system. From here you can:

  • Add User — create a new user with first/last name, username, email, password, role (User or Superuser) and active status
  • Edit (yellow pencil) — update an existing user's details
  • Permissions (teal key) — grant or revoke access to individual modules (Properties, Tenants, Suppliers, etc.). Superusers have automatic full access — their permissions cannot be changed.
  • Disable (red icon) — prevent a user from logging in (without deleting them)
  • Re-enable (green tick) — restore access to a previously disabled user
  • Delete (red trash) — permanently remove a user (only available for disabled users)
Menu Preference

A shortcut to your My Profile page where you can switch between the Top Menu and Sidebar navigation styles.

Best Practices
  • Check invoices on the 2nd — if the 1st-of-month auto-run didn't fire for any reason, click Generate Invoices on the 2nd. The system only creates ones that don't already exist, so clicking it is always safe.
  • Use Generate Lease Agreement for consistency — the template-based wizard ensures every lease has the same structure, language and required fields. Manually drafted leases drift over time.
  • Keep Title Deeds and Lease Agreements up to date — these are the legal anchors of every property and tenancy. Upload as soon as you receive the signed document.
  • Configure Notifications first — before relying on alerts (overdue invoices, expense approvals, daily reports), use the Notifications button to set the right TO / CC recipients in Administration Notification Settings.
  • Disable rather than delete users — if someone leaves, disable their account. You can always re-enable later. Delete is only available for disabled users for that reason.
  • Don't bother editing Superuser permissions — Superusers automatically have full access to every module. Module checkboxes for Superusers are read-only and ignored.
  • End dates in red mean expired — on the Manage Lease Agreements page, any end date shown in red is a lease that has already ended. Renew or close out promptly.
If invoices didn't generate automatically: Check your scheduled job logs first. Then click Generate Invoices to create any missing invoices on the fly. If invoices still don't appear, check that the tenant has an active lease covering the current month.
