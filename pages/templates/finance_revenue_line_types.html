Revenue Line Types — User Guide
Define the categories of income that appear as rows in the Profit & Loss Statement
  • Overview
  • The Table
  • Add / Edit
  • Tips
What are Revenue Line Types?

A Revenue Line Type defines the category of an income stream — the label that will appear as a row in the Revenue section of the Profit & Loss Statement.

Where Revenue Types describe when income is collected (the months pattern), Revenue Line Types describe what the income actually is. They're the answer to: "What kind of income is this?"

Two examples already in your system:
  • Rental — "Rental Income" (the rent paid by tenants)
  • Levies — "Levies" (building/community levies recovered from tenants)

These are the two rows you'll currently see in the Revenue section of the P&L for any property.

Where this fits in the bigger picture

Revenue Line Types are the second piece of the three-part Revenue configuration:

  1. Revenue Types — when income is collected (the months pattern)
  2. Revenue Line Types (this page) — what the income is called on the P&L
  3. Revenues — the actual records: a property + a Line Type + a Type + an amount

Every Revenue record on every property must be tagged with a Line Type. The P&L then groups all matching records together to produce a single Revenue row labelled with that Line Type's name.

Permissions: This page is restricted to Superusers. Standard users won't see Configuration in the Financials menu.
Reading the Table

The table is intentionally simple — each row is one Line Type with three columns:

  • Revenue Line Type — the short name. This is what shows up as the row label in the P&L (e.g. Rental, Levies).
  • Revenue Line Type Description — a longer, human-readable description. Currently this is for your own reference; the P&L uses the short name only.
  • Details — an Edit button to modify the Line Type.
What you see here = what shows up in the P&L. If your table has rows for Rental and Levies, your P&L Revenue section will have a row for each. Add a third Line Type (e.g. Parking), and as soon as a Revenue record is tagged with it, a third row will appear in the P&L.
Adding a Revenue Line Type

Click Add New in the top-right to open the Add Line Type form. There are just two fields:

  1. Revenue Line Type Name — the short label. This is what appears in the P&L, so keep it short and clear (e.g. Rental, Levies, Parking, Storage).
  2. Revenue Line Type Description — a longer explanation for your own records (e.g. "Monthly rent paid by tenants").

Click Save in the top-right. The new Line Type appears in the list and is immediately available to assign to Revenue records.

Editing an existing Revenue Line Type

Click the Edit button on the relevant row. The form is identical to the Add form, with both fields pre-filled. Update either field and click Save.

Renaming has a downstream effect. If you change the Name of a Line Type that's already in use, the row in the Profit & Loss Statement will immediately show the new name — including for all historical periods. The underlying numbers don't change, only the label. This is usually fine (e.g. tidying up a typo), but be aware that older P&L screenshots will no longer match the live page.
Don't repurpose a Line Type. If you want a new income category, create a new Line Type. Don't rename Rental to Parking — every existing Revenue record tagged as Rental will suddenly be reclassified as Parking in the P&L.
Practical Tips
  • Keep names short. The Name appears in P&L tables where space is tight — one or two words is ideal (Rental, Levies, Parking). Save the longer wording for the Description field.
  • Use the Description field generously. It's free-form and only visible here, so use it to capture the full meaning — especially for Line Types where the short name might be ambiguous later.
  • Think about how you want the P&L to read. Each Line Type becomes a row in the Revenue section. If you want Rental and Parking as separate rows in the P&L, create them as separate Line Types. If you want them combined into a single Rental row, just use one Line Type and tag both kinds of revenue with it.
  • Don't over-categorise. Two or three Line Types is enough for most portfolios. Adding too many produces a fragmented P&L where every row is small, making the bigger picture harder to read.
  • Be consistent across properties. If one property's monthly rent is tagged Rental and another's is tagged Rent Income, they'll appear as two different rows in the consolidated P&L. Pick one name and stick with it.
  • Plan for new income streams. If you start charging tenants for parking, storage, or utilities separately, add a Line Type before adding the first Revenue record — that way the P&L category is ready when the income starts flowing in.
