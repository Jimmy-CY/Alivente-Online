{% comment %} ============================================================================ Reusable PDF Viewer Component ============================================================================ Renders PDFs inline using Mozilla's PDF.js library. Works on all browsers and devices, including Android Chrome which doesn't support inline PDF embedding natively. USAGE: {% include 'components/pdf_viewer.html' %} Then in your page's JavaScript, call: openPdfViewer(pdfUrl, modalTitle, downloadFilename) For example: openPdfViewer('/media/leases/abc.pdf', 'Lease Agreement (John Smith)', 'lease_smith.pdf'); The component provides: - A Bootstrap modal with PDF.js canvas viewer - Page navigation (Previous/Next) - Zoom controls (In/Out/Fit) - Download button (always) - Share button (mobile only, uses Web Share API to attach the file to WhatsApp / Mail / AirDrop / etc. via the native OS share sheet) - Mobile-responsive (full-screen on phones) - Image fallback for non-PDF files (jpg/jpeg/png) BOTTOM BUTTON LAYOUT: Desktop: [⬇ Download] [Close] (right-aligned, unchanged) Mobile: [📤 Share (wide)] [⬇] [✕] (single row, Share is primary) If Web Share API is unavailable, Share is hidden and Download becomes the wide primary instead: [⬇ Download (wide)] [✕] ============================================================================ {% endcomment %}
